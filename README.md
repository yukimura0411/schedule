# 📅 スタイリッシュ・ダークカレンダー Webアプリケーション (PHP)

PHPとSQLiteで動作する、洗練された**ダークカラー基調のスタイリッシュなカレンダーWebアプリケーション**です。  
外部パッケージ（Composer等）は不要で、PHP標準の機能のみで即座に動作します。

---

## ✨ 主な特徴・機能

- **スタイリッシュなダークテーマ UI**
  - 深みのあるグラファイト/スレートブラック（`#0b0f19`）を基調とした洗練されたモダンデザイン
  - グラスモーフィズム（すりガラス効果）と微細なグラデーション
  - 日曜（ローズ）、土曜（スカイブルー）、平日（スレート）の落ち着いた視認性の高い配色
  - 当日日付のグラデーション発光バッジ
  - 日本の祝日・振替休日・国民の休日を自動判定してスタイリッシュなバッジで表示
- **予定（イベント）の管理**
  - カレンダーの日付セルをクリックして即座に予定を作成
  - タイトル、日付、終日設定、開始/終了時刻、6色のカラーパレット、詳細メモに対応
  - 予定のクリックで編集・削除モーダルを表示
- **表示モード切り替え & リアルタイム検索**
  - 「カレンダー表示」と「予定一覧リスト表示」をワンタップで切り替え可能
  - タイトルやメモから目的の予定を素早く探せるリアルタイム検索機能
- **データ永続化**
  - SQLite（`calendar.db`）を使用し、サーバーを終了しても予定データを保持

## 🚀 起動方法

### 方法 1: 起動スクリプトを使用（おすすめ）

ターミナルで以下のコマンドを実行します：

```bash
cd /Users/yukinishimura/Documents/calendar
./start.sh
```

ローカルサーバーが起動し、自動的にブラウザでカレンダーが開きます。

---

### 方法 2: 手動で起動

```bash
cd /Users/yukinishimura/Documents/calendar
php -S localhost:8000
```

起動後、ブラウザで [http://localhost:8000](http://localhost:8000) にアクセスしてください。
